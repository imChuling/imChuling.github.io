# As You Read — 声音与交互设计

浏览这个网站本身就是一件作品：访客不是在"播放一段配乐"，而是在改变一段正在发生的声音。走到哪里、怎么动、停多久、回不回头，都会留在声音里。

## 信号链

```
声床 (每个 section 一段循环 pad)  ─┐
旋律 (FM 钟声，网页实时生成)       ├─▶ Max/RNBO 导出的处理链 ─▶ 声像 ─▶ 扬声器
擦玻璃噪声 (带通噪声)              ─┘    颗粒 → 过载 → 板式混响
```

- 处理链来自 Max 9 / RNBO 1.3.5 的 Web Export（JR-Granular + RNBO Guitar Pedals 的 Overdrive、Plate Reverb），在浏览器里运行。
- 音源在网页侧生成或预渲染，全部送进同一条链，所以所有声音都是"同一个房间里"的。
- 旋律另有 22% 的干声直通，保证音头清晰。

## 开场

- 开屏计数 000 → 100 时磨砂玻璃逐渐变清，页面在后面"显影"。
- 到 100 停住，出现 **Enter with sound ↗ / Enter quietly**。点击即是浏览器要求的用户手势，声音淡入 2 秒。
- 导航栏 **Sound ●** 随时开关；开着时显示当前声场名（Arrival / Projects / Stage / Story / Hello / Close）。

## 五个 section，五种底色

每个 section 一段 24 秒无缝循环的 pad（四层微失谐、缓慢起伏、第五泛音闪烁），切换时 2–3 秒交叉淡变。上面的处理参数也各自不同。

| Section | 和声 | 声床性格 | 处理 |
|---|---|---|---|
| Hero · Arrival | D dorian / Dm9 | 暖、开阔、能听出和弦 | 颗粒 30%，混响中等 |
| Projects | A major, sus | 高一个音区、亮、轻 | 颗粒短而密，高频抬 |
| Music · Stage | E dorian，开放五度 | 最厚、最宽 | 颗粒 82%，低五度，过载最重 |
| Story | Bb lydian | 高、稀、远 | 颗粒最长，低七度，混响 92%、jitter 大 |
| About · Hello | Cmaj9 | 暖、贴近、安静 | 颗粒退回，混响收近 |
| 详情 sheet · Close | 沿用所在 section | 收到耳边 | 颗粒 22%，混响最近，高频亮 |

## 旋律层

FM 钟声音色，C5–A6 音区，四种比率轮换（钟 / 玻璃 / 空心 / 金属）。每个 section 一条 7 音音阶，和各自的声床是同一套和声。

- **随机漫步**：每 2–5 秒落一个音，沿音阶一步步走，偶尔跨两步、跳八度；30% 的音带一个应答音或三连音。
- 鼠标在页面左侧偏低音、右侧偏高音；动得快音落得密；8 秒不动渐稀。
- **自发琶音**：在一处停约 10 秒后，每 9–18 秒自己弹一段五音琶音。
- **慢漂移**：9 秒和 23 秒周期的 LFO 微调颗粒位置、颗粒长度、混响大小——不动也在变。

## 交互 → 声音

| 访客的动作 | 声音的回应 |
|---|---|
| 进入一个 section | 声床淡变；四音动机（奇数次进入上行，偶数次下行）；颗粒密度猛一下再回落 |
| 回到走过的 section | 颗粒混合 +14、混响 +12、尾音更长——走过的地方更厚 |
| 在一处停留 | 45 秒内慢慢变厚 |
| 8 秒没动 | 退向最素的声床；再碰鼠标时一个"醒来"的三连音 |
| 滚动 | 每约 140px 拨一个音阶音（往下上行、往上下行）；滚得快音更亮；长滚动停下落在根音 |
| 往上回看 | 音高微微下沉 |
| 鼠标快速划动 | 颗粒瞬间变密、立体声变宽、高频开 |
| 鼠标往右 / 往左 | 音高微升 / 微降（±1.2 半音） |
| 鼠标往上 / 往下 | 颗粒变短变紧 / 变长变松 |
| 鼠标左右位置 | 整个声场轻微左右声像 |
| 鼠标上下位置 | 偏上更亮，偏下更厚 |
| hover 卡片 / 封面 / 曲目 | 三连音上挑；颗粒变短、音高微升；四首曲目各有自己的音程 |
| 点击任何可点的东西 | 和弦绽开（四音，最高音高八度）+ stutter：颗粒间隔缩到 1/3、音高上弹 3 半音，0.5 秒回落 |
| 点导航链接 | 从当前音滑向目的地 section 的根音 |
| hover 导航 | 极轻一声 tick |
| 选中文字 | 选中的字"哼"起来（根音三角波，越多越亮）；每 12 字往上念一个音；松手落一个轻和弦 |
| 擦 Story 的玻璃 | 颗粒退、混响变亮变"玻璃"、过载减；一层带通噪声跟着擦的速度响；高音区短促玻璃音；停手约 6 秒慢慢起雾 |
| Story 翻章 | 每章一个带五度的音，越后越高 |
| 打开详情 sheet | 一串下行到低八度，进入 Close 声场 |
| 关掉 sheet | 上行回到 section 五音，恢复原声场 |
| 播放视频 | 乐谱 0.3 秒内退下；暂停 / 结束 / 关 sheet 时回来 |
| 鼠标移出窗口 | 音量退到 60%，回来恢复 |
| 滚到页面最底 | 一次完整终止和弦（6 秒）；回滚过一半后重新武装 |
| 切到别的标签页 / 点出去 | 声音继续，只要页面还开着 |
| 关掉 Sound | 一个柔和的释放和弦，再 1.5 秒淡出 |

## 文件

| 文件 | 作用 |
|---|---|
| `assets/as-you-read/site-score.mjs` | 全部交互与声音逻辑；`SCENES` 是五个声场的参数，`SCALES` 是五条音阶 |
| `assets/as-you-read/beds/*.mp3` | 五段声床 |
| `assets/as-you-read/tools/make-beds.py` | 声床生成脚本（和弦、音区、起伏都在 `BEDS` 表里），改完 `python3` 跑一下 |
| `assets/as-you-read/rnbo-engine.mjs` | RNBO 引擎宿主 |
| `assets/as-you-read/rnbo-export/scene.export.json` | Max 导出的处理链 |
| `js/sheet.js` | 详情页以 sheet 方式在主页内打开；视频 ducking |
| `js/main.js` | 开屏、光标、Story 擦玻璃等页面本身的动效 |

## 调音

浏览器控制台输入 `document.querySelector('.nav-sound').score`，能看到当前 scene、bed、residue、motion、focus、wipe 等所有状态和参数目标值。想改某个 section 的声音，改 `SCENES` 里那一行；想改旋律音阶，改 `SCALES`；想改某个手势的力度，`site-score.mjs` 里每个系数旁都有一行注释说明它是什么。
